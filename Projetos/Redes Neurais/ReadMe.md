# 🧠 Implementação de uma Rede Neural do Zero com Python

Este projeto apresenta a implementação de uma **Rede Neural Artificial (Artificial Neural Network - ANN)** desenvolvida do zero utilizando apenas **Python** e **NumPy**, sem o uso de bibliotecas de Machine Learning como TensorFlow, Keras ou Scikit-learn.

O principal objetivo é compreender o funcionamento interno de uma rede neural, desde a inicialização dos pesos até o processo de treinamento e geração de previsões.

---

## 📌 Objetivos

- Entender os fundamentos das Redes Neurais Artificiais.
- Implementar manualmente o algoritmo de treinamento.
- Compreender como os pesos são ajustados durante o aprendizado.
- Explorar o funcionamento da função de ativação Sigmoide.
- Consolidar conhecimentos em Machine Learning através da prática.

---

## 🚀 Tecnologias Utilizadas

- Python 3
- NumPy
- Jupyter Notebook

---

## 🧠 Conceitos Abordados

Durante o desenvolvimento deste projeto foram aplicados conceitos como:

- Redes Neurais Artificiais
- Perceptron
- Inicialização de pesos
- Bias
- Função de Ativação Sigmoide
- Feedforward
- Cálculo do erro
- Ajuste de pesos
- Processo de treinamento
- Predição de novos dados

---

## ⚙️ Fluxo do Algoritmo

O modelo segue as seguintes etapas:

1. Inicialização dos pesos e bias.
2. Entrada dos dados de treinamento.
3. Cálculo da saída da rede (Feedforward).
4. Cálculo do erro.
5. Atualização dos pesos.
6. Repetição do processo durante várias épocas.
7. Realização de previsões utilizando o modelo treinado.

---

## 💡 Aprendizados

Este projeto foi desenvolvido com foco no aprendizado dos fundamentos do Machine Learning.

Embora bibliotecas como TensorFlow e PyTorch simplifiquem a criação de modelos, implementar uma rede neural manualmente proporciona uma compreensão muito mais profunda sobre como os algoritmos realmente funcionam.
