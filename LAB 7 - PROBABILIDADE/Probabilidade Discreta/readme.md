📊 Probabilidades Discretas com Python e SciPyUm guia prático e visual para modelagem e análise de distribuições de probabilidade discretas utilizando Python.🎯 O que é o projeto e o que aconteceEste projeto é um notebook interativo focado na exploração e análise de variáveis aleatórias discretas e suas principais distribuições de probabilidade.Através de simulações computacionais, cálculos teóricos e visualizações gráficas geradas com NumPy, SciPy e Matplotlib, o projeto demonstra como quantificar a incerteza em experimentos contáveis e fenômenos do mundo real — desde o lançamento de dados e moedas até a contagem de eventos em um intervalo fixo de tempo.🚀 Objetivos🎲 Simular Experimentos Aleatórios: Utilizar geração de números pseudo-aleatórios para reproduzir eventos probabilísticos clássicos.📈 Visualizar Funções de Probabilidade: Construir gráficos de barras claros para entender a distribuição e o comportamento dos dados.🧮 Calcular Probabilidades Exatas: Aplicar funções de massa de probabilidade (PMF) para resolver problemas práticos de contagem.🧠 Compreender Fenômenos Reais: Conectar conceitos matemáticos teóricos a aplicações práticas de análise de dados.🛠️ TecnologiasAs ferramentas e bibliotecas utilizadas no projeto são:🐍 Python — Linguagem base do projeto.🔢 NumPy — Computação numérica e geração de amostragem aleatória.🧪 SciPy (stats) — Módulo estatístico para cálculo de distribuições de probabilidade.📊 Matplotlib — Criação e personalização dos gráficos.🧠 Conceitos abordadosO projeto cobre fundamentos teóricos e práticos das distribuições discretas:Conceitos Fundamentais: Análise descritiva de variáveis discretas, esperança matemática (média), variância e desvio padrão.Distribuição Uniforme Discreta: Modelagem de cenários onde todos os resultados possuem probabilidades idênticas (Ex: Lançamento de um dado justo).Distribuição Binomial: Análise do número de sucessos em um número fixo de tentativas independentes de Bernoulli (Ex: Quantidade de caras em $n$ lançamentos).Distribuição de Poisson: Contagem de eventos que ocorrem em um determinado intervalo contínuo dada uma taxa média $\lambda$ (Ex: Chegada de clientes em um estabelecimento).Distribuição Geométrica: Cálculo do número de tentativas necessárias até obter o primeiro sucesso.🔄 Fluxo do algoritmoO código executa uma sequência lógica bem definida para cada análise estatística:📦 Importação de Dependências: Carregamento dos módulos numpy, scipy.stats e matplotlib.pyplot.📖 Introdução e Parâmetros: Definção dos parâmetros do experimento (ex: taxa $\lambda$, quantidade de ensaios $n$, probabilidade $p$).⚙️ Processamento e Simulação:Execução de simulações com números aleatórios (np.random).Cálculo dos valores teóricos de probabilidade usando a PMF do SciPy.📝 Exibição de Resultados: Saída formatada dos valores estatísticos calculados no terminal/notebook.📉 Renderização Gráfica: Construção dos gráficos de barras (plt.bar) para representação visual dos resultados.
